# Известные проблемы

## Авторизация через VK ID

OAuth через VK ID требует проверки на production-сервере с настроенными VK ID
redirect URI и `device_id`. На локальном сервере и эмуляторе этот сценарий пока
не считается проверенным. Клиент и backend уже используют единый callback-контракт:
одноразовый параметр `code`.
